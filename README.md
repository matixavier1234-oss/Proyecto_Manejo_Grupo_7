# Proyecto_Manejo_Grupo_7
# E-Commerce de Motocicletas - Proyecto GitFlow

Proyecto desarrollado para la materia **Manejo y Configuración de Software** de la Carrera de Software en la Universidad Técnica de Ambato. El objetivo principal es aplicar buenas prácticas de control de versiones mediante la simulación de un entorno real de desarrollo colaborativo utilizando el modelo GitFlow.

## Tecnologías Utilizadas
* HTML5
* CSS3 (Bootstrap)
* JavaScript (Vanilla)

## Configuración Local
1. Clonar el repositorio: `git clone <url-del-repositorio>`
2. Cambiar a la rama de integración: `git checkout develop`
3. Abrir el archivo `index.html` en el navegador para visualizar la aplicación.
